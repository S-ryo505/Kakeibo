# おうち家計簿 — GitHub Pages で公開する

Netlify と違って **ログインが切れてもサイトは止まりません**。
一度置けば、無料のまま、期限なしで動き続けます。

---

## 置きかた（初回だけ。20分ほど）

初回だけはパソコンのほうが楽です。**一度終われば、あとはパソコン不要**です。

### 1. GitHub のアカウントを作る
<https://github.com> で登録（無料）。すでにあればそのまま。

### 2. リポジトリ（置き場）を作る
- 右上の「+」→ **New repository**
- **Repository name**: `kakeibo`
  - URL に出るので、気になるなら `kakeibo-7f3a` のように
    推測されにくい名前でも構いません
- **Public** を選ぶ ← 無料プランでは公開が必要です（理由は下の「公開について」）
- **Create repository**

### 3. ファイルを置く
このフォルダの中身 **7つ** をアップロードします。
（フォルダごとではなく、**中のファイルを選ぶ**のがポイント）

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `icon-maskable-512.png`
- `apple-touch-icon.png`
- `.nojekyll` ← 見えない場合は隠しファイルを表示にする

手順: **Add file** → **Upload files** → 7〜8個を選ぶ → **Commit changes**

> `.nojekyll` が選べなくても動きます。念のための保険です。

### 4. 公開をオンにする
- **Settings**（歯車）→ 左の **Pages**
- **Source**: `Deploy from a branch`
- **Branch**: `main` / `/ (root)` → **Save**
- 1〜3分待つと、同じ画面に URL が出ます

```
https://<あなたのユーザー名>.github.io/kakeibo/
```

### 5. 奥様に渡す
その URL を LINE で送る。奥様は **Chrome** で開き、
右上「⋮」→ **アプリをインストール**。
ホーム画面におうちのアイコンが出ます。

---

## 更新のしかた（ここからはスマホだけでできます）

1. GitHub でリポジトリを開く
2. `index.html` をタップ → 鉛筆マーク（編集）or **Upload files** で上書き
3. **Commit changes**
4. 1〜3分で反映。奥様が次に開いたとき、自動で新しくなります

アプリを入れ直す必要はありません。

---

## 公開について（大事なところ）

無料プランでは、置き場（リポジトリ）を **公開** にする必要があります。
ただし **公開されるのは「空っぽの道具」だけ** です。

| 公開されるもの | 公開されないもの |
| --- | --- |
| アプリの画面と仕組み | 家計のデータすべて |
| 費目の分けかたのルール | カード明細・銀行明細 |
| 一般家庭のめやすの数字 | 収入・貯蓄率 |

入力したデータは **奥様の端末のブラウザの中だけ** に保存され、
GitHub にも、どこのサーバーにも送られません。

念のため、勤務先を判定する文字（`ﾆﾂｻﾝ` など）は
**最初から空** にしてあります。
⚙️設定 →「給与ふりこみ元の名前」に入れてください。端末の中だけに残ります。

> 空のままでも、`ｷﾕｳﾘﾖｳ`／`ｼﾖｳﾖ` という表示から
> 給与・賞与は正しく拾えます。入れると表示が
> 「給与とみられる入金」→「勤務先からの給与」に変わるだけです。

## 最初にやること（奥様）

1. ⚙️設定 → 🏦 の枠に **銀行のCSV**
2. ⚙️設定 → 💳 の枠に **カードのCSV**
3. ⚙️設定 → 毎月の収入・世帯人数・給与ふりこみ元
4. ✏️入力 → 固定費（家賃・保険・習いごと）

銀行だけ入れた状態では、**わざと「のこり」を出しません**。
カードで買った分が抜けていて、実際よりずっと余って見えてしまうためです。
カードのCSVを入れると出ます。

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 404 が出る | 公開直後は数分かかります。URL 末尾の `/` を忘れていないか確認 |
| 「アプリをインストール」が出ない | Chrome で開いていない（Miブラウザ等）。リンク長押し →「Chromeで開く」 |
| 更新が反映されない | 1〜3分待つ。それでもだめならアプリを一度閉じて開き直す |
| データが消えた | ⚙️設定 →「読み込む」でバックアップを戻す。CSV があれば作り直せます |

Xiaomi の端末では、インストール後に
`設定 → アプリ → おうち家計簿 → 電池 → 制限なし` にしておくと、
勝手に終了されにくくなります。
